# SQL Learning Practice

A structured repository documenting my progression from SQL fundamentals to advanced analytical queries.

The goal of this repository is to build practical SQL skills through short, focused exercises covering data filtering, aggregation, joins, analytical queries, and window functions.

## Learning Approach

Each exercise contains:

- a short problem statement;
- the SQL concept being practised;
- a brief explanation of the approach;
- the final SQL query.

New topics are added gradually as they are studied and practised.
